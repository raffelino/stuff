So wird gespielt

Bis zu vier Spieler wählen eine Figur und einen Namen.

Wer an der Reihe ist, tippt auf den Würfel. Der Würfel zeigt eine Rechenart: Plus, Minus, Mal oder Geteilt. Dazu gibt es einen Joker (Rechenart selbst aussuchen) und Aussetzen.

Dann erscheint eine Rechenaufgabe im eingestellten Zahlenraum. Wird sie innerhalb der Zeit richtig gelöst, zieht die Figur vor: Plus 1 Feld, Minus 2, Mal 3, Geteilt 4 (einstellbar). Bei falscher Antwort oder abgelaufener Zeit bleibt die Figur stehen.

Wer zuerst das Ziel erreicht, gewinnt!
